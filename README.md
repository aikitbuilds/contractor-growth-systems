# Contractor Growth Systems

## Project Overview
This project is the website for Contractor Growth Systems, designed to help small and medium-sized contractors scale their businesses through systematic approaches to sales, marketing, and operations.

## Technologies Used
- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Express server

## Local Development

```sh
# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at http://localhost:8080
